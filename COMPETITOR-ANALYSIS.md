# Competitor SEO Analysis — uSwap Zero

## Direct Competitors (Crypto Swap Services)

### 1. ChangeNow (changenow.io)

| Factor | Assessment |
|--------|-----------|
| Domain Authority | High (~60+) |
| Indexed Pages | 10,000+ (token pair pages, blog, guides) |
| Content Strategy | Extensive blog, "how to buy" guides for every token, comparison pages |
| Schema Markup | SoftwareApplication, FAQPage, BreadcrumbList |
| Technical SEO | Fast, well-structured, proper meta tags |
| Fee Model | 0.25–0.5% markup (not disclosed on landing pages) |
| Weakness | Hides fee structure; no open-source code; heavy JavaScript tracking |

**Keyword gaps to exploit:** "changenow fees", "changenow hidden fees", "changenow alternative no fees"

### 2. SimpleSwap (simpleswap.io)

## Competitive Advantages for SEO

| Advantage | How to Leverage |
|-----------|----------------|
| Zero fees (provable) | Target "zero fee" and "no fee" keywords; create fee comparison content |
| No JavaScript tracking | Target privacy keywords; demonstrate with page source |
| Open source | Target "open source" keywords; link to GitHub for E-E-A-T |
| Verifiable builds | Unique trust signal — no competitor offers this |
| Pure HTML/CSS | Fastest page loads in the category — excellent Core Web Vitals |
| On-chain fee data | Case study with real transaction evidence is linkable content |

## Content Gap Analysis

| Content Type | ChangeNow | SimpleSwap | StealthEX | uSwap Zero |
|-------------|-----------|------------|-----------|------------|
| Token pair pages | 5,000+ | 3,000+ | 2,000+ | 0 |
| Blog posts | 200+ | 100+ | 150+ | 0 |
| How-to guides | 50+ | 30+ | 40+ | 1 |
| Comparison pages | 10+ | 5+ | 5+ | 1 (case study) |
| FAQ content | Yes | Yes | Yes | No |
| API documentation | Yes | Yes | Yes | Partial (ureply docs) |
| Fee transparency page | No | No | No | No (opportunity!) |

### Priority Content to Create

1. **Fee transparency page** — No competitor has one. Show exactly what users pay (market maker spread only) with live examples.
2. **Token pair landing pages** — Start with top 20 most-swapped pairs. Competitors have thousands; we need at least the high-traffic ones.
3. **Comparison pages** — vs ChangeNow, vs SimpleSwap, vs StealthEX. Focus on fee comparison with verifiable data.
4. **"Hidden fees in crypto swaps" article** — Expand the case study into a broader educational piece targeting informational queries.
5. **FAQ section** — Target featured snippets and AI citations for common swap questions.
